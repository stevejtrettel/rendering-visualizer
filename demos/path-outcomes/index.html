SHOWS: how a walk ends. One algorithm (plain path tracing) held fixed while the ending changes — it reaches an emitter and flashes, it is killed mid-flight by Russian roulette, or it leaves the scene and never returns. Two of the three contribute nothing: this is the only page carrying the failure vocabulary, and the sample counter says how many tries each ending took, which is the variance story in miniature. Escaping needs the open scene (a closed box has nowhere to escape to), so that mode swaps scene and vantage.
Sibling page: path-strategies holds the sample fixed and varies the algorithm instead.
