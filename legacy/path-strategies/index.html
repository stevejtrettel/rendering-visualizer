SHOWS: which algorithm builds the path. One pixel, one sample, held fixed while the integrator changes — plain path tracing bounces and hopes; NEE tries the light from every vertex; BDPT grows a second path out of the light and connects the two. All three run to the same 6-bounce cap with Russian roulette off, so the pictures are comparable and nothing dies early. The first segment of every one of them is the camera ray leaving the pinhole.
