# legacy demos

The pre-rebuild demo set (2026-08-04), kept for reference only.

These pages are **not built, not typechecked, and not expected to run** —
they predate the talk-visuals stage (locked 16:9, `t`-driven clock,
one-button PNG/video export) and each still carries its own `index.html`
and bespoke CSS. They are here so the rebuild can see what a figure used
to do and what capabilities it exercised, not to be maintained.

`tsconfig.json` includes only `src`, `demos` and `tests`, so nothing here
affects `npm run typecheck`.

When a figure is rebuilt under `demos/`, delete its legacy folder.
